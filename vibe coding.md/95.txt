# Vibe Coding 開發Prompt紀錄與專案說明

- **專題主題**：無痕野餐，無酒也歡 (大三影展專題介紹)
- **開發方式**：使用 AI 輔助開發 (Vibe Coding)

---

## 🤖 專案使用之 Prompt 指令紀錄

### 1. 網頁架構與 SEO 規劃
> **Prompt**: "請幫我建立一個 responsive HTML5 網頁，主題為大三影展專題『無痕野餐，無酒也歡』，需要包含完整的 SEO head 標籤（title, description, keywords）、導覽列 (Navbar) 以及側邊欄 (Sidebar)，並區分四個主要分頁。"

### 2. Grid System 與 RWD 響應式排版
> **Prompt**: "請寫出 css/style.css 樣式表，使用 CSS Grid 來實作側邊欄與主內容的雙欄架構，並加入 @media (max-width: 768px) 響應式設計，讓行動裝置看的時候可以自動切換成直向單欄排版。"

### 3. 永續綠色視覺風格與元件設計
> **Prompt**: "請幫我調整 CSS 視覺色系為綠色永續風格，並寫出卡片式佈局 (Card Grid) 來呈現專題的三大核心亮點。"
