# 逢甲大學影展專題：無痕野餐，無酒也歡

歡迎來到我的影展專題網站！

## 專題介紹
本專題以「無痕野餐，無酒也歡」為主題，透過網站介紹影展理念、活動內容與相關資訊。

## 網站內容
- **首頁**：影展主題與活動介紹
- **概念介紹**：呈現影展的核心理念
- **製作介紹**：分享網站與專題的製作過程
- **聯絡我們**：提供聯絡資訊

## 使用技術
- HTML：建立網站架構
- CSS：網頁視覺設計與排版
- Grid System：網頁版面配置
- RWD：響應式網頁設計

## 專案檔案
- `index.html`：網站首頁
- `concept.html`：概念介紹
- `production.html`：製作介紹
- `contact.html`：聯絡頁面
- `css/style.css`：網站樣式

## Vibe Coding
本專題使用 Vibe Coding 輔助網站開發，詳細指令請參考 `vibe-coding.md`。
