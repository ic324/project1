# 逢甲大學影展專題：無痕野餐，無酒也歡

## 一、專題介紹
本專題以 **「無痕野餐，無酒也歡」** 為核心主題，旨在推廣在戶外聚會、野餐與放鬆的同時，落實永續環保生活。我們倡導「不製造垃圾、自備環保餐具與環保杯」，並推廣享用無酒精飲品的健康質感生活型態。本網站透過圖文整合與影像紀錄，完整呈現影展核心理念與推廣價值。

## 二、網站設計理念
* **核心概念**：結合戶外野餐與環保永續，傳遞自然、減塑、無負擔的生活美學。
* **視覺風格**：採用清新自然的色調（如大地綠、暖木色、米白色底），搭配充足的留白與實地拍攝的活動照片，營造舒適、沉浸式的閱讀氛圍。

## 三、目標客群
* 喜歡戶外活動、熱愛親近大自然的青年學生與社會大眾。
* 關注永續環保、減塑生活實踐與質感生活方式的族群。

## 四、網站功能與內容
1. **企劃理念**：深入介紹專題核心理念與「無痕野餐」的推廣價值。
2. **影片介紹**：呈現影展活動的核心短片與現場影像紀錄。
3. **活動內容**：介紹無酒精飲品、環保餐具準備與戶外聚會指南。
4. **參訪與資訊**：提供相關活動場域、幕後花絮與參訪資訊。

## 五、Vibe Coding 開發與 Prompt 說明

在本次專題網頁開發過程中，我透過生成式 AI 工具協助進行網頁架構規劃與程式碼編寫。以下為實際使用的主要 Prompt 紀錄與開發脈絡：

### Prompt 01 | 網站架構與視覺定位
> **Prompt 內容**：
> 「請扮演一位熟悉 UI/UX 與前端網頁設計的網頁設計師。我正在製作大三影展專題網站，主題為『無痕野餐，無酒也歡』，推廣不製造垃圾、自備環保杯與無酒精的質感戶外生活。請協助規劃網頁結構，包含頂部導覽列、側邊欄、主內容區與 RWD 響應式排版，並建議清新自然的配色（如大地綠與暖木色）。」

### Prompt 02 | CSS 模組化切割與樣式設計
> **Prompt 內容**：
> 「請協助將網頁的 CSS 樣式進行模組化切割，以符合專題維護需求。需要分成三個檔案：`style.css`（全域與變數）、`layout.css`（導覽列、側邊欄與網格系統 Grid/Flexbox 佈局）、以及 `responsive.css`（處理手機與平板的 RWD 響應式斷點設定）。」

### Prompt 03 | SEO 設定與內容優化
> **Prompt 內容**：
> 「請在 HTML 的 `<head>` 標籤中加入完整的 SEO 基本設定，包含適合的 `<title>` 網頁標題與 `<meta name="description">` 敘述，確保搜尋引擎能正確抓取『無痕野餐』影展專題的核心內容。」

## 六、使用技術
* **HTML5**：建立網頁語意化結構。
* **CSS3**：樣式設計與模組化切割。
* **CSS Grid & Flexbox**：網格排版與元件對齊。
* **RWD 響應式網頁設計**。
* **SEO 基本設定**。
* **GitHub & Vercel**：版本控制與雲端部署。
